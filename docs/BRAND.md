# VerveQ brand

The core of the VerveQ ONE brand (owner-approved 2026-10-21, decisions 1–4).
How the app is built is in [APP_OVERVIEW.md](APP_OVERVIEW.md). This page is
the short rulebook for anything that shows the brand: the app, share images,
emails, static pages, reels.

## Single source

| What | Where |
|---|---|
| Colors (source of truth) | `app/src/index.css` (`:root`) |
| Colors for everything outside the app | `app/src/styles/tokens.json`, generated by `node app/scripts/exportTokens.mjs` from `index.css`. A test fails if it drifts. **The content factory imports this file.** It doesn't restate hex values. |
| Colors for canvas painters in the app | `app/src/lib/brandTokens.ts`, parity-tested against `index.css` |
| The mark + wordmark geometry | `app/src/components/ui/brandMark.geometry.json` (glyph outlines) |
| React component | `app/src/components/ui/BrandMark.tsx` (`mark` / `wordmark` / `lockup`) |
| Standalone SVGs | `app/public/brand/*.svg` (`node app/scripts/exportBrandMark.mjs`) |
| App icons, favicon, Instagram avatar | `node app/scripts/generatePwaIcons.mjs` → `app/public/` |
| Canvas lockup | `app/src/lib/brandCanvas.ts` |
| Node/SVG lockup (icons, SEO cards, SEO header) | `app/scripts/lib/brand.mjs` |

## Logo

- **The mark** is an ink rounded square tilted **−4°** with **"VQ"** in lime
  (Space Grotesk 700 outlines). Don't redraw it, recolor it, straighten it or
  set it in a live font. Use the geometry file or the exported SVGs.
- **The wordmark** is **VERVEQ** in JetBrains Mono 700, uppercase, tracked
  `0.18em`. In sentences the name is written "VerveQ". The orange split-Q
  is retired.
- **The lockup** is the mark, then the wordmark, both vertically centered. The
  wordmark's cap height is about 30–40% of the mark's height.
- **On ink**, the mark keeps its faint cream inner rim (about 22% opacity) so
  the square doesn't disappear into the ground. The wordmark is cream.
- **On cream**, the wordmark is ink and no rim is needed.
- **Where a platform masks the icon** (iOS, Android maskable, the Instagram
  circle), the mask itself is the square. Fill the canvas with ink and draw
  only the lime VQ, still tilted −4°. Keep the letters inside the safe circle.
- **Emails** can't rely on images or web fonts. Use a small ink tile with lime
  "VQ" in bold Arial, then "VERVEQ" in bold Courier New with wide tracking.

## Palette

| Token | Hex | Role |
|---|---|---|
| ink | `#121212` | The ground of every screen and image. It's also the text color on any colored fill. |
| cream | `#FFF7F0` | Text on ink. The ground of long-form reading cards (rules, legal, SEO articles). |
| lime | `#C6FF1A` | **The one action color**: the thing to tap, plus small accents. Never a large fill, and it never casts a shadow. |
| blue | `#0084FF` | Mode accent: Who's Older |
| pink | `#FF3DC5` | Mode accent: Missing Letters |
| orange / yellow | `#FF6A00` / `#FFCD1A` | Secondary mode accents. Orange is also the action color on cream reading cards. |
| right / wrong | `#00D170` / `#FF3633` | Answer feedback only |

Text on any colored fill is **ink, never white**. White fails contrast on
every brand fill.

**Mode accents:** Who's Older is blue, Missing Letters is pink, and THE
WEEKEND and THE DRAW use a **lime outline** (never a lime fill). An accent
marks which game you're in. It never replaces the lime action.

## Type

- **Space Grotesk 700**: headings, body, buttons.
- **JetBrains Mono 700**: numbers, eyebrows, codes, the wordmark.
- Both are self-hosted (`app/public/fonts/`). Static 700 TTFs for
  server-side rasterizing are in `app/scripts/og/fonts/`. They are
  ASCII-only, so accented copy uses the full Space Grotesk embedded in
  `app/convex/lib/shareCardFontData.ts`.
- The static SEO pages use `system-ui` for body text on purpose. Web fonts
  that swap in late caused layout shift (CLS 0.13). Their logo is outlined
  SVG, so it needs no font.

## Voice

- **Plain words.** Write "players", not "shirts". Write "pick a squad", not
  insider jargon. Cold-traffic and paid copy is always plain. The organic
  social lane may keep its in-jokes.
- **Numbers carry units**: "10 questions", "60 seconds", "4.5m", "+12 pts".
- **Sentence case** for headlines, buttons and UI copy ("Can you beat it?").
  UPPERCASE is only for mono eyebrows and the wordmark.
- **Short and direct.** Lead with the action ("Play free · no sign-up"). Don't
  hype, and don't use exclamation marks.
- **Honest numbers.** Only show a standing when it flatters ("Better than X%"
  at X ≥ 50). Otherwise show the streak. Never put an evaluative number
  before a vote.

## Share images and previews

Link-preview cards (1200×630) and share PNGs use the same look:

- an ink ground with a faint lime diagonal stripe
- the lockup at top-left
- an eyebrow in mono
- a cream headline
- one lime pill as the action
- the URL at bottom-right in mono, at 62% opacity

See `app/scripts/renderOgCards.mjs`, `app/seo/og.mjs` and
`app/convex/lib/duelShareCard.ts`. Preview caches key on the image URL, so
**bump the version** when artwork changes:

- per-game cards: `OG_VERSION` in `seo/entries.mjs`
- SEO page cards: `OG_DIR` in `seo/og.mjs`
- duel card: `CARD_STYLE_VERSION` in `convex/lib/duelShareCard.ts`
- icons: `ICON_VERSION` in `vite.config.ts`, plus the `?v=` on the icon links
